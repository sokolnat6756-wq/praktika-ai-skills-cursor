1
Открываем готовый проект

Cursor → File → Open Folder → выбираем папку своего сайта. Убедись, что открыта именно корневая папка.

Открой GitHub Desktop → выбери проект → в Changes создай коммит «Сохранение сайта перед редизайном». Сохраняем через кнопки, без терминала и Git-команд.

ЭТАП 0210 МИН

Подключаем AI Skills.

Skills — инструкции для Cursor Agent, которые учат его определённому рабочему процессу: анализировать дизайн, работать с типографикой, создавать анимации и проверять результат.

Самый простой способ — один запрос в Cursor Agent. Нажми кнопку ниже, затем вставь скопированный текст в чат Agent внутри открытого проекта. Он создаст шесть файлов SKILL.md в нужных папках. Перед подтверждением посмотри список изменений. Никаких ZIP и ручной установки.
ГЛАВНЫЙ ШАГ · 1 МИНУТА

Установить все шесть Skills

Скопируй запрос → вставь в Cursor Agent → подтверди создание файлов. Agent не должен заменять существующие Skills без разрешения.

Что должно получиться: Cursor покажет шесть новых папок в .cursor/skills/. После установки попроси Agent перечислить их названия и пути. В случае ошибки используй кнопку установки отдельного Skill ниже.

ЭТАП 0310 МИН

Собираем референсы.

Наш пример — mkvision.studio ↗. Мы берём оттуда три принципа: анимации при прокрутке, необычную типографику и нестандартное расположение блоков. Цвета и брендинг создаём свои.

Для анимаций одного скриншота недостаточно. Внизу есть кнопка, которая копирует готовое описание движения для файла motion-notes.md. Вставь текст в Cursor Agent, чтобы он создал этот файл в design/references/ рядом с твоими изображениями.
Важно: скриншот показывает только кадр. Он не объясняет, как движется блок. Для сложных эффектов нужен короткий скринкаст + текстовый файл motion-notes.md с таймкодами. Пример описания анимаций можно скопировать выше одной кнопкой.
